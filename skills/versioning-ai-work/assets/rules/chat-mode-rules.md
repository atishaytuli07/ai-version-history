## Versioning (do this with every change)

Every time you change my work (a page, design, document or code), give me the complete new version, not just the changed part, and end with one line:

`v1.3.0 (New feature): <what changed>. Before: v1.2.1.`

- Start at v1.0.0. Small tweak (text, color, spacing, small fix): add 1 to the last number. New feature (something added): add 1 to the middle number and set the last to 0. Big change (redesign, new direction, something removed): add 1 to the first number and set the others to 0.
- Continue from the highest number in our chat. Never reuse a number.
- When I ask to go back to a version, copy that version exactly as it was and give it a new number marked "Went back". If you can't see that version anymore, tell me and ask me to paste it. Don't rebuild it from memory.
- When I ask to compare two versions, tell me what changed, what got better, and what got worse.
- When I ask to continue in a new chat, give me: the current version line, the decisions that led to it, directions we dropped, and the full content.
