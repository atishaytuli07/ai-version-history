Version history for Lovable

Every change you make in Lovable gets a version number, like v2.4.1.

A small button in your preview lists your versions: what changed and when. You can go back to any version. Going back is saved as a new version, so you can undo it too.

What the numbers mean

Take v2.4.1:

  • The first number (2) goes up for a big change, like a redesign.
  • The second number (4) goes up for a new feature, like a new page or section.
  • The last number (1) goes up for a small fix, like new text or a color.

When you go back to an older version, the middle number goes up. Your newer versions are all still there.

Choose a setup

Lite needs no GitHub. It takes about 10 minutes, all inside Lovable.

  • Good for trying it out on personal or small projects.
  • To go back, you use Lovable's History. The version button tells you which change to pick.
  • If Lovable forgets to describe a change, that change gets no version. Your code is still in Lovable's History.
  • Your version list is stored in your app's database. Anyone with your app's public key can read it and add to it, so don't use Lite for anything private.

Pro uses GitHub. It takes about 15 minutes.

  • Every change gets a version, even if Lovable forgets to describe it.
  • To go back, type in Lovable's chat: "go back to v3.4.5".
  • On GitHub you can lock versions so they can't be deleted. For a private repo this needs a paid GitHub plan.

Pick one per project. If you already use GitHub, pick Pro.

It has been tested live in Lovable apps made before May 13, 2026. Apps made since then use a newer setup (TanStack Start). The steps cover both, but the newer setup hasn't been tested live yet.

Before you start

  • Going back never deletes a version. Your history stays until you delete it. Keep a backup of anything important.
  • Going back brings back your code, not your data. Rows in your database and uploaded files stay as they are, just like with Lovable's own History.
  • If a change added or changed database tables, going back can break the app, because the tables don't go back. Ask Lovable to fix it.

Is Lite right for this project? Read this first.

Your app reads and adds versions with its public key (the key your app uses to reach its database). This key is in every copy of your published app. So anyone can read your version list (version numbers, summaries and dates). Anyone can also add versions to it.

The database blocks the worst cases:

  • A new version must have the next number.
  • Texts must be short.
  • At most 20 new versions can be added in a minute.
  • Nobody can change or delete versions from the app.

-- ai-versions (Lite): one table that holds every version.
-- Restoring old code in Lovable never touches database rows, so the list survives a restore.
--
-- Who can do what: the app reads and adds versions with the public key, so anyone who has
-- that key can too. These rules limit the damage: a new version must be exactly the next
-- number, texts are short, at most 20 versions a minute, and nobody can change or delete
-- versions from the app. You can still delete rows yourself in the SQL editor.

create table if not exists public.ai_versions (
  version text primary key
    check (version ~ '^v[0-9]{1,4}\.[0-9]{1,4}\.[0-9]{1,4}$'),
  entry_hash text not null check (length(entry_hash) between 1 and 64),
  level text not null check (level in ('start', 'patch', 'minor', 'major', 'restore')),
  summary text not null default '' check (length(summary) <= 200),
  note text not null default '' check (length(note) <= 500),
  reason text not null default '' check (length(reason) <= 300),
  restored_from text
    check (restored_from is null or restored_from ~ '^v[0-9]{1,4}\.[0-9]{1,4}\.[0-9]{1,4}$'),
  created_at timestamptz not null default now()
);

alter table public.ai_versions enable row level security;

-- Every new row must be the next version after the newest one, so nobody can jump
-- ahead (for example to v999.0.0) and take over the numbering.
create or replace function public.ai_versions_next_only() returns trigger
language plpgsql set search_path = public as $$
declare
  last_version text;
  maj int; mnr int; pat int;
  expected text;
  recent int;
begin
  new.created_at := now();
  select version into last_version from public.ai_versions
    order by split_part(substr(version, 2), '.', 1)::int desc,
             split_part(substr(version, 2), '.', 2)::int desc,
             split_part(substr(version, 2), '.', 3)::int desc
    limit 1;
  if last_version is null then
    expected := 'v1.0.0';
    if new.level <> 'start' then
      raise exception 'ai_versions: the first version must be v1.0.0 (start)';
    end if;
  else
    maj := split_part(substr(last_version, 2), '.', 1)::int;
    mnr := split_part(substr(last_version, 2), '.', 2)::int;
    pat := split_part(substr(last_version, 2), '.', 3)::int;
    expected := case new.level
      when 'patch' then format('v%s.%s.%s', maj, mnr, pat + 1)
      when 'minor' then format('v%s.%s.0', maj, mnr + 1)
      when 'restore' then format('v%s.%s.0', maj, mnr + 1)
      when 'major' then format('v%s.0.0', maj + 1)
      else null
    end;
  end if;
  if expected is null or new.version <> expected then
    raise exception 'ai_versions: % is not the next version (expected %)', new.version, coalesce(expected, 'none');
  end if;
  if new.restored_from is not null
     and not exists (select 1 from public.ai_versions where version = new.restored_from) then
    raise exception 'ai_versions: % does not exist', new.restored_from;
  end if;
  select count(*) into recent from public.ai_versions where created_at > now() - interval '1 minute';
  if recent >= 20 then
    raise exception 'ai_versions: too many new versions in one minute';
  end if;
  return new;
end;
$$;

drop trigger if exists ai_versions_next_only on public.ai_versions;
create trigger ai_versions_next_only
  before insert on public.ai_versions
  for each row execute function public.ai_versions_next_only();

-- The app may read and add versions. There are no update or delete rules,
-- so versions can't be changed or removed from the app.
drop policy if exists "Anyone can read versions" on public.ai_versions;
drop policy if exists "Anyone can add versions" on public.ai_versions;
create policy "Anyone can read versions"
  on public.ai_versions for select using (true);
create policy "Anyone can add versions"
  on public.ai_versions for insert with check (true);

const VERSION_RE = /^v(\d+)\.(\d+)\.(\d+)$/;
const semver = (v: string) => (VERSION_RE.exec(v)?.slice(1).map(Number) ?? [0, 0, 0]) as number[];
const byVersionDesc = (a: Row, b: Row) => {

const clip = (s: unknown, n: number) => String(s ?? "").replace(/\s+/g, " ").trim().slice(0, n);

// Stable fingerprint of the AI's entry. Same entry = same code state.
function entryHash(e: Entry): string {
  const s = JSON.stringify([clip(e.id, 40), clip(e.bump, 20).toLowerCase(), clip(e.summary, 200), clip(e.reason, 300), clip(e.prompt, 500)]);
  let h1 = 0xdeadbeef, h2 = 0x41c6ce57;
  for (let i = 0; i < s.length; i++) {
    const c = s.charCodeAt(i);
    h1 = Math.imul(h1 ^ c, 2654435761);
    h2 = Math.imul(h2 ^ c, 1597334677);
  }
  h1 = Math.imul(h1 ^ (h1 >>> 16), 2246822507) ^ Math.imul(h2 ^ (h2 >>> 13), 3266489909);
  h2 = Math.imul(h2 ^ (h2 >>> 16), 2246822507) ^ Math.imul(h1 ^ (h1 >>> 13), 3266489909);
  return (4294967296 * (2097151 & h2) + (h1 >>> 0)).toString(36);
}

// What (if anything) to record for the current code. Rows may be in any order.
function nextRow(rows: Row[], e: Entry, hash: string): Row | null {
  const sorted = [...rows].sort(byVersionDesc);
  const latest = sorted[0];
  const base = { entry_hash: hash, note: "", reason: "", restored_from: null };
  if (!latest) {
    return { ...base, version: "v1.0.0", level: "start", summary: "Versioning switched on" };
  }
  if (latest.entry_hash === hash) return null; // nothing new
  let [M, m, p] = semver(latest.version);
  const original = sorted.filter((r) => r.entry_hash === hash).pop(); // oldest = the original
  if (original) {
    return {
      ...base, version: `v${M}.${m + 1}.0`, level: "restore", restored_from: original.version,
      summary: `Went back to ${original.version}`,
    };
  }
  const bump = clip(e.bump, 20).toLowerCase();
  const level = bump === "major" || bump === "minor" ? bump : "patch";
  if (level === "major") [M, m, p] = [M + 1, 0, 0];
  else if (level === "minor") [m, p] = [m + 1, 0];
  else p += 1;
  return {
    ...base, version: `v${M}.${m}.${p}`, level,
    summary: clip(e.summary, 200) || "Change",
    note: clip(e.prompt, 500),
    reason: [bump !== level ? `Unknown level "${bump}", saved as a small tweak.` : "", clip(e.reason, 300)]
      .filter(Boolean).join(" "),
  };
}

// Records the current entry if needed, then returns the full list (newest first).
async function syncDatabase(s: Store, e: Entry | undefined): Promise<Version[]> {
  for (let attempt = 0; attempt < 3; attempt++) {
    const rows = await s.listAiVersions();
    const row = e ? nextRow(rows, e, entryHash(e)) : null;
    if (!row) return rows.sort(byVersionDesc).map(toVersion);
    const result = await s.addAiVersion(row);
    if (result === "ok") {
      return [{ ...row, created_at: new Date().toISOString() }, ...rows].sort(byVersionDesc).map(toVersion);
    }
    // "duplicate": another open preview saved this number first; read again and retry
  }
  return (await s.listAiVersions()).sort(byVersionDesc).map(toVersion);
}

// After going back, later versions are built on the version that was restored.
function withBuiltOn(list: Version[]): Version[] {
  let base: string | null = null;
  const out = [...list].reverse().map((v) => {
    if (v.level === "restore") base = v.restored_from ?? base;
    return { ...v, built_on: v.level === "restore" ? null : base };
  });
  return out.reverse();
}

function when(iso: string | null): { short: string; full: string } {
  if (!iso) return { short: "", full: "" };
  const d = new Date(iso);
  if (Number.isNaN(d.getTime())) return { short: "", full: "" };
  const full = d.toLocaleString(undefined, {
    day: "numeric", month: "short", year: "numeric", hour: "numeric", minute: "2-digit",
  });
  const mins = Math.round((Date.now() - d.getTime()) / 60000);
  let short: string;
  if (mins < 1) short = "just now";
  else if (mins < 60) short = `${mins} min ago`;
  else if (mins < 24 * 60) short = `${Math.round(mins / 60)} h ago`;
  else if (mins < 48 * 60) short = "yesterday";
  else short = d.toLocaleDateString(undefined, { day: "numeric", month: "short" });
  return { short, full };
}

## Versioning (mandatory on every change)

In the same edit as every code change, overwrite `src/ai-version.ts` with:

```ts
export const aiVersion = {
  id: "a new random 6-letter code, different for every change",
  bump: "patch",
  summary: "One line: what changed (max 100 chars)",
  reason: "One line: why this bump level",
  prompt: "",
};
```

Choose `bump`:
- `patch`: small tweak, same features. Colors, text, spacing, sizes, icons, a small bug fix.
- `minor`: something new, same design direction. New section, component, page, form, feature or integration.
- `major`: direction changed. Full redesign, new layout or navigation, new design system, removing a feature or page, changing the data model.
- Unsure between two levels: pick the lower one and say so in `reason`.

Rules:
- Every change needs a fresh `src/ai-version.ts` with a new `id` and a description of that change. A change without it gets no version.
- Leave `prompt` empty. Prompts are only saved if a rule below asks for it, because anyone with the app's public key can read the version list.
- Never edit `src/components/VersionPill.tsx` or `src/lib/ai-versions-store.ts`. Never change, delete or drop the `ai_versions` table or its rows.
- Keep `<VersionPill />` rendered once in the root layout (`src/routes/__root.tsx`, or `src/App.tsx` in older apps). It only shows in preview, never on the live site.
- Never invent version numbers. The version pill assigns them.
- If the user says a level was wrong ("that was major"), use their judgment for similar changes from now on and mention it in `reason`.

## Going back to a version

- Don't rewrite old code from memory. Going back is done with Lovable's History → Restore.
- If the user names a version ("go back to v3.4.5") or describes one ("before the redesign"), find it in the version pill's list (the `ai_versions` table), then tell them its summary and the date and time it was saved, so they can pick the matching change in History and click Revert. If more than one version could match, ask which.
- After a restore, treat the restored code as the truth. Don't re-apply changes from versions after the restored one unless the user asks for them again.

Do this step last. If Lovable gets the rules earlier, it may change the files from Steps 3 and 4.

#!/usr/bin/env node
// ai-versions: gives every change on the default branch its own version.
//
// Source of truth = annotated git tags named vMAJOR.MINOR.PATCH. Tags live
// outside the files, so restoring old code in Lovable can never erase them.
//
// Each run versions every commit since the newest tagged one on the branch
// (first-parent), so a run that GitHub cancelled or skipped is caught up next time.
// For each such commit (oldest first):
//   1. Already has a version tag        -> skip (safe to re-run).
//   2. No app-code changes vs parent     -> skip (kit files and our list updates aren't app code).
//   3. App code identical to a version   -> "restore" (bump RESTORE_BUMP).
//   4. Looks like a near-identical restore -> "restore" (about vX).
//   5. AI wrote a fresh pending.json     -> use its bump + summary.
//   6. Anything else                     -> automatic patch.
// Going back from chat: when the branch has .ai-versions/restore.json
// ({"version": "v3.4.5"}), the code of that version is brought back as a new
// commit, versioned as "Restored to v3.4.5", and the request file is removed.
// Finally it rewrites public/ai-versions.json (read by the in-app version pill)
// from the tags and pushes it, so the list heals itself even after a restore.
//
// The kit itself (.github/, .ai-versions/, the VersionPill component, the list) is
// never treated as app code and is never rolled back by a restore.
//
// Env: AFTER (commit to version up to), BRANCH (branch to push the list and restores to),
//      GITHUB_REPOSITORY, GITHUB_SERVER_URL, GH_TOKEN (for releases),
//      NO_RELEASE=1, NO_LEDGER=1, PILL_NOTES=yes (show prompts), GITHUB_STEP_SUMMARY.

import { execFileSync } from 'node:child_process';
import { createHash } from 'node:crypto';
import { writeFileSync, appendFileSync, mkdtempSync, mkdirSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join, dirname } from 'node:path';

const PENDING = '.ai-versions/pending.json';
const LEDGER = 'public/ai-versions.json'; // written by this script only; ignored when comparing code
const REQUEST = '.ai-versions/restore.json'; // "go back to vX", written by the builder's AI; not code
// Kit files: versioning machinery, not the user's app. Never versioned, never rolled back.
const isKitFile = (f) => f === LEDGER || f.startsWith('.github/') || f.startsWith('.ai-versions/')
  || /(^|\/)VersionPill\.tsx$/.test(f);
const RESTORE_BUMP = 'minor'; // going back is a visible change, but not a new direction
const FIRST_VERSION = 'v1.0.0';
const MAX_COMMITS = 100; // safety cap for one push
const LEDGER_MAX = 500; // newest versions kept in the in-app list
const BUMPS = ['patch', 'minor', 'major'];
const TAG_RE = /^v(\d+)\.(\d+)\.(\d+)$/;

const git = (...args) =>
  execFileSync('git', args, { encoding: 'utf8', stdio: ['ignore', 'pipe', 'pipe'], maxBuffer: 64 << 20 }).trim();
const tryGit = (...args) => {
  try { return git(...args); } catch { return null; }
};
const oneLine = (s, max) => String(s ?? '').replace(/\s+/g, ' ').trim().slice(0, max);

// "What the code is" = every file except the kit.
const sigCache = new Map();
const codeSig = (rev) => {
  if (!sigCache.has(rev)) {
    const list = git('ls-tree', '-r', rev).split('\n').filter((l) => !isKitFile(l.split('\t')[1] || '')).join('\n');
    sigCache.set(rev, createHash('sha1').update(list).digest('hex'));
  }
  return sigCache.get(rev);
};
const changedFiles = (parent, commit) =>
  (parent ? git('diff', '--name-only', parent, commit) : git('ls-tree', '-r', '--name-only', commit))
    .split('\n').filter((f) => f && !isKitFile(f));

// ---------- existing versions ----------
const parse = (t) => TAG_RE.exec(t)?.slice(1).map(Number);
const cmp = (a, b) => a[0] - b[0] || a[1] - b[1] || a[2] - b[2];

const tags = (tryGit('tag', '-l', 'v*') || '').split('\n').filter((t) => TAG_RE.test(t));
tags.sort((a, b) => cmp(parse(a), parse(b)));

const commitToTag = new Map();
const sigToTag = new Map(); // oldest version wins = the original, not a later restore
const seenPendingBlobs = new Set();
const pendingBlobToTag = new Map(); // which version first carried this pending.json
for (const t of tags) {
  const c = git('rev-list', '-n', '1', t);
  commitToTag.set(c, t);
  const sig = codeSig(c);
  if (!sigToTag.has(sig)) sigToTag.set(sig, t);
  const blob = tryGit('rev-parse', `${c}:${PENDING}`);
  if (blob) {
    seenPendingBlobs.add(blob);
    if (!pendingBlobToTag.has(blob)) pendingBlobToTag.set(blob, t);
  }
}
let latest = tags.at(-1) || null;
const warnings = [];
const created = [];

// ---------- commits to process ----------
// Everything since the newest tagged commit on the first-parent line, not just this
// push: GitHub may cancel a queued run, and the next run must catch up.
const after = process.env.AFTER || git('rev-parse', 'HEAD');
function untaggedSince(tip) {
  const line = (tryGit('rev-list', '--first-parent', `--max-count=${MAX_COMMITS + 1}`, tip) || '')
    .split('\n').filter(Boolean);
  const out = [];
  for (const c of line) {
    if (commitToTag.has(c)) return out.reverse();
    out.push(c);
  }
  return null; // no tagged commit within reach (history rewritten, or very long gap)
}
let commits = latest ? untaggedSince(after) : [];
if (latest && commits === null) {
  warnings.push(`No versioned commit found in the last ${MAX_COMMITS} commits; versioning only the newest one.`);
  commits = [after];
}

// ---------- helpers ----------
const nextVersion = (bump) => {
  let [M, m, p] = parse(latest);
  if (bump === 'major') [M, m, p] = [M + 1, 0, 0];
  else if (bump === 'minor') [m, p] = [m + 1, 0];
  else p += 1;
  let v = `v${M}.${m}.${p}`;
  while (tryGit('rev-parse', '-q', '--verify', `refs/tags/${v}`)) v = `v${M}.${m}.${++p}`;
  return v;
};

const repoUrl = process.env.GITHUB_REPOSITORY
  ? `${process.env.GITHUB_SERVER_URL || 'https://github.com'}/${process.env.GITHUB_REPOSITORY}`
  : null;


function publish(version, commit, info) {
  const prev = latest;
  const meta = {
    version, previous: prev, commit, kind: info.kind, bump: info.bump,
    summary: info.summary, reason: info.reason, prompt: info.prompt,
    restored_from: info.restoredFrom || null,
  };
  git('tag', '-a', version, commit, '-m', `${version}: ${info.summary}\n\n${JSON.stringify(meta, null, 2)}`);
  try {
    git('push', 'origin', `refs/tags/${version}`);
  } catch (e) {
    console.error(`Could not save ${version} to GitHub.\n${String(e.stderr || e.message).trim()}\n` +
      'Fix: Settings -> Actions -> General -> Workflow permissions -> "Read and write", then Re-run this job.\n' +
      'If you added a tag ruleset, make sure "Restrict creations" is NOT ticked.');
    process.exit(1);
  }
  latest = version;
  commitToTag.set(commit, version);
  const sig = codeSig(commit);
  if (!sigToTag.has(sig)) sigToTag.set(sig, version);
  created.push(meta);
  console.log(`${version}  ${info.bump.padEnd(5)}  ${info.summary}`);

  if (process.env.NO_RELEASE === '1') return;
  const lines = [
    `**Change:** ${info.summary}`,
    `**Level:** ${info.bump}${info.kind === 'ai' ? ' (chosen by the AI)' : ''}`,
    info.reason ? `**Why this level:** ${info.reason}` : null,
    info.prompt ? `**Prompt:** ${info.prompt}` : null,
    info.restoredFrom ? `**Restored from:** ${info.restoredFrom}${info.exact ? ' (code is identical)' : ' (most files match)'}` : null,
    `**Commit:** ${commit.slice(0, 7)}`,
    prev && repoUrl ? `**Compare with ${prev}:** ${repoUrl}/compare/${prev}...${version}` : null,
  ].filter(Boolean);
  const dir = mkdtempSync(join(tmpdir(), 'aiv-'));
  const notes = join(dir, 'notes.md');
  writeFileSync(notes, lines.join('\n\n') + '\n');
  try {
    execFileSync('gh', ['release', 'create', version, '--verify-tag',
      '--title', `${version}: ${oneLine(info.summary, 80)}`, '--notes-file', notes],
      { stdio: ['ignore', 'pipe', 'pipe'] });
  } catch (e) {
    warnings.push(`Release page for ${version} failed (the version itself is saved): ${String(e.stderr || e.message).trim()}`);
  }
}

function readPending(commit, parent) {
  const changed = parent
    ? git('diff', '--name-only', parent, commit).split('\n')
    : git('ls-tree', '-r', '--name-only', commit).split('\n');
  if (!changed.includes(PENDING)) return { why: 'AI did not update pending.json' };
  const blob = tryGit('rev-parse', `${commit}:${PENDING}`);
  if (!blob) return { why: 'pending.json was deleted' };
  if (seenPendingBlobs.has(blob)) {
    return { why: 'pending.json reused an old entry', hintTag: pendingBlobToTag.get(blob) };
  }
  let data;
  try { data = JSON.parse(git('cat-file', 'blob', blob)); } catch { return { why: 'pending.json is not valid JSON' }; }
  const bump = String(data.bump || '').toLowerCase().trim();
  if (!BUMPS.includes(bump)) return { why: `pending.json has unknown bump "${data.bump}"`, data };
  seenPendingBlobs.add(blob);
  return { ok: true, bump, data };
}

// A restore that is not byte-identical (e.g. the tool left one file alone):
// pending.json went back to an old version's entry AND the code now differs
// from that version in only a few files (at most 2, or under 20% of what changed).
function looksLikeRestore(commit, parent, tag) {
  if (!parent) return false;
  const changed = changedFiles(parent, commit).filter((f) => f !== PENDING);
  const offFromTag = git('diff', '--name-only', `${tag}^{commit}`, commit).split('\n')
    .filter((f) => f && !isKitFile(f));
  return offFromTag.length <= 2 || offFromTag.length < 0.2 * changed.length;
}

if (!latest) {
  const c = after;
  publish(FIRST_VERSION, c, {
    kind: 'baseline', bump: 'baseline', summary: 'Baseline: versioning switched on',
    reason: 'First version. Everything before this commit is not versioned.', prompt: '',
  });
  commits = [];
}

// ---------- main loop ----------
function versionCommit(c) {
  if (commitToTag.has(c)) return;
  const parent = tryGit('rev-parse', `${c}^`);
  if (parent && codeSig(parent) === codeSig(c)) {
    console.log(`skip ${c.slice(0, 7)}: no code changes`);
    return;
  }
  const subject = oneLine(git('log', '-1', '--format=%s', c), 100) || 'Change';

  const match = sigToTag.get(codeSig(c));
  if (match) {
    publish(nextVersion(RESTORE_BUMP), c, {
      kind: 'restore', bump: RESTORE_BUMP, restoredFrom: match, exact: true,
      summary: `Restored to ${match}`,
      reason: 'Code is identical to an earlier version, so this was a restore.', prompt: '',
    });
    return;
  }

  const p = readPending(c, parent);
  if (!p.ok && p.hintTag && looksLikeRestore(c, parent, p.hintTag)) {
    publish(nextVersion(RESTORE_BUMP), c, {
      kind: 'restore', bump: RESTORE_BUMP, restoredFrom: p.hintTag, exact: false,
      summary: `Restored to about ${p.hintTag}`,
      reason: `pending.json and most changed files went back to ${p.hintTag}, so this looks like a restore.`,
      prompt: '',
    });
    return;
  }
  if (p.ok) {
    publish(nextVersion(p.bump), c, {
      kind: 'ai', bump: p.bump,
      summary: oneLine(p.data.summary, 100) || subject,
      reason: oneLine(p.data.reason, 200),
      prompt: oneLine(p.data.prompt, 300),
    });
  } else {
    publish(nextVersion('patch'), c, {
      kind: 'auto', bump: 'patch', summary: subject,
      reason: `Automatic patch: ${p.why}.`, prompt: '',
    });
  }
}

// After bringing back old files, put the kit back as it is now: old workflow files
// would be refused by GitHub, and old scripts or settings would quietly downgrade the kit.
function keepKitFrom(tip) {
  const tipKit = git('ls-tree', '-r', '--name-only', tip).split('\n').filter((f) => f && isKitFile(f));
  for (const f of git('ls-files').split('\n').filter((x) => x && isKitFile(x) && !tipKit.includes(x))) {
    tryGit('rm', '-q', '--cached', '--', f);
    tryGit('clean', '-q', '-f', '--', f);
  }
  if (tipKit.length) git('checkout', tip, '--', ...tipKit);
  tryGit('rm', '-q', '--cached', '--ignore-unmatch', '--', REQUEST);
  tryGit('clean', '-q', '-f', '--', REQUEST);
}

// A request counts only if the app code hasn't changed since it was made. If the user
// kept working after asking (or a failed run left it behind), it's dropped: an old
// request must never roll back newer work.
function requestIsFresh(tip, blob) {
  const line = (tryGit('rev-list', '--first-parent', `--max-count=${MAX_COMMITS}`, tip) || '')
    .split('\n').filter(Boolean);
  for (const c of line) {
    if (tryGit('rev-parse', `${c}:${REQUEST}`) === blob && tryGit('rev-parse', `${c}^:${REQUEST}`) !== blob) {
      return codeSig(c) === codeSig(tip);
    }
  }
  return false;
}

function handleRestoreRequest() {
  const branch = process.env.BRANCH || 'main';
  for (let attempt = 1; attempt <= 3; attempt++) {
    if (tryGit('fetch', '-q', 'origin', branch) === null) return;
    const tip = git('rev-parse', 'FETCH_HEAD');
    const blob = tryGit('rev-parse', `${tip}:${REQUEST}`);
    if (!blob) return; // nothing requested
    let req = {};
    try { req = JSON.parse(git('cat-file', 'blob', blob)); } catch {}
    let v = oneLine(req.version, 40).toLowerCase();
    if (v && !v.startsWith('v')) v = `v${v}`;
    const exists = TAG_RE.test(v) && tryGit('rev-parse', '-q', '--verify', `refs/tags/${v}`) !== null;
    const fresh = requestIsFresh(tip, blob);

    git('checkout', '-q', '-B', 'ai-versions-restore', tip);
    let message;
    let restoring = false;
    if (!fresh) {
      git('rm', '-q', '--ignore-unmatch', REQUEST);
      message = `Drop an old go-back request (${v || 'no version'})`;
      notice = `An old request to go back to ${v || 'a version'} was dropped, because newer changes came after it. Ask again if you still want it.`;
    } else if (!exists) {
      git('rm', '-q', '--ignore-unmatch', REQUEST);
      message = `Restore request: ${v || 'no version given'} doesn't exist`;
      notice = `Couldn't go back to ${v || '(no version given)'}: that version doesn't exist. Check the number in the version list and ask again.`;
    } else {
      git('read-tree', '-u', '--reset', `${v}^{tree}`); // app files become exactly that version
      keepKitFrom(tip);
      const note = oneLine(req.note, 100);
      message = `Restore ${v} (asked in chat)${note ? `: ${note}` : ''}`;
      restoring = true;
    }
    if (tryGit('diff', '--cached', '--quiet', tip) !== null) return; // nothing to change
    git('commit', '-q', '-m', message);
    const head = git('rev-parse', 'HEAD');
    const pushed = (() => {
      try { git('push', '-q', 'origin', `HEAD:refs/heads/${branch}`); return null; } catch (e) { return String(e.stderr || e.message).trim(); }
    })();
    if (pushed !== null) {
      console.log(`Restore push was rejected (attempt ${attempt}): ${pushed}`);
      notice = null;
      if (attempt === 3) {
        console.log(`::error::Could not apply the go-back request: ${pushed}`);
        process.exitCode = 1;
      }
      continue;
    }
    console.log(message);
    if (restoring) {
      if (codeSig(head) === codeSig(tip)) notice = `Already at ${v}: the code didn't change.`;
      versionCommit(head);
    }
    return;
  }
  warnings.push('Could not apply the go-back request after 3 tries. It will be dropped on the next run; ask again then.');
}

function buildLedger() {

  all.sort((a, b) => cmp(parse(b), parse(a))); // newest first
  const builtOn = new Map(); // after going back, later versions are built on that version
  let base = null;
  for (const t of [...all].reverse()) {
    let m = {};
    try { m = JSON.parse(tryGit('tag', '-l', '--format=%(contents:body)', t) || '{}'); } catch {}
    if (m.kind === 'restore') base = m.restored_from || base;
    else if (base) builtOn.set(t, base);
  }
  const versions = all.slice(0, LEDGER_MAX).map((t) => {
    const date = tryGit('for-each-ref', '--format=%(taggerdate:iso-strict)', `refs/tags/${t}`) || null;
    let m = {};
    try { m = JSON.parse(tryGit('tag', '-l', '--format=%(contents:body)', t) || '{}'); } catch {}
    return {
      version: t,
      date,
      level: m.kind === 'restore' ? 'restore' : m.kind === 'baseline' ? 'start' : (m.bump || 'patch'),
      summary: m.summary || '',
      note: HIDE_NOTES ? '' : m.prompt || '',
      reason: HIDE_NOTES ? '' : m.reason || '',
      restored_from: m.restored_from || null,
      built_on: builtOn.get(t) || null,
    };
  });
  const out = { versions };
  if (notice) out.notice = { text: notice, date: new Date().toISOString() };
  return JSON.stringify(out, null, 2) + '\n';
}

function shouldShow(): boolean {
  if (typeof window === "undefined") return false;
  try {
    const q = new URLSearchParams(window.location.search).get("versions");
    if (q === "on" || q === "off") localStorage.setItem("ai-versions-pill", q);

    if (saved === "off") return false;
    if (saved === "on") return true;

    /* storage blocked: fall through to the defaults */
  }

  return (
    h === "localhost" ||
    h === "127.0.0.1" ||
    h.endsWith(".lovableproject.com") ||
    h.startsWith("id-preview--") ||
    h.startsWith("preview--") ||
    h.includes("webcontainer") ||

}

function when(iso: string | null): { short: string; full: string } {
  if (!iso) return { short: "", full: "" };
  const d = new Date(iso);
  if (Number.isNaN(d.getTime())) return { short: "", full: "" };
  const full = d.toLocaleString(undefined, {
    day: "numeric", month: "short", year: "numeric", hour: "numeric", minute: "2-digit",
  });
  const mins = Math.round((Date.now() - d.getTime()) / 60000);
  let short: string;
  if (mins < 1) short = "just now";
  else if (mins < 60) short = `${mins} min ago`;
  else if (mins < 24 * 60) short = `${Math.round(mins / 60)} h ago`;
  else if (mins < 48 * 60) short = "yesterday";
  else short = d.toLocaleDateString(undefined, { day: "numeric", month: "short" });
  return { short, full };
}

                    key={v.version}
                    className={`aivp-row${isOpen ? " is-open" : ""}`}
                    style={{ ["--c" as string]: color }}
                    tabIndex={0}
                    role="button"
                    aria-expanded={hasMore ? isOpen : undefined}
                    onClick={() => setExpanded(isOpen ? null : v.version)}
                    onKeyDown={(e) => {
                      if (e.key === "Enter" || e.key === " ") {
                        e.preventDefault();
                        setExpanded(isOpen ? null : v.version);
                      }
                    }}
                  >
                    <span className="aivp-rail" aria-hidden="true">
                      <span className={`aivp-dot l-${v.level}`} />
                    </span>
                    <div>
                      <div className="aivp-top">
                        <span className="aivp-v">{v.version}</span>
                        <span className="aivp-lvl">{LEVEL_LABEL[v.level] ?? v.level}</span>
                        {i === 0 && <span className="aivp-now">Now</span>}
                        <time className="aivp-time" dateTime={v.date ?? undefined} title={t.full}>{t.short}</time>
                      </div>
                      <div className="aivp-sum">{v.summary}</div>
                      {v.built_on && <div className="aivp-on">Built on {v.built_on}</div>}
                      {v.note && <div className="aivp-note">“{v.note}”</div>}
                      {isOpen && (v.restored_from || v.reason || t.full) && (
                        <div className="aivp-more">
                          {v.restored_from && <div>Same code as {v.restored_from}</div>}
                          {v.reason && v.level !== "restore" && <div>{v.reason}</div>}
                          {t.full && <div>{t.full}</div>}
                        </div>
                      )}
                    </div>
                  </li>
                );
              })}
            </ol>
          )}
          <div className="aivp-foot">To go back, ask in chat, for example: “go back to v1.2.0”.</div>
        </div>
      )}
      <button
        className="aivp-pill"
        onClick={() => setOpen((o) => !o)}
        aria-expanded={open}
        aria-label={current ? `Version ${current.version}. Show version history` : "Show version history"}
      >
        <span
          className="aivp-dot l-patch"
          style={{ margin: 0, background: current ? `var(--${current.level})` : "var(--patch)" }}
          aria-hidden="true"
        />
        {label}
        <svg className="aivp-chev" viewBox="0 0 10 10" aria-hidden="true">
          <path d="M2 6.5 5 3.5 8 6.5" fill="none" stroke="currentColor" strokeWidth="1.6" strokeLinecap="round" />
        </svg>
      </button>
    </div>
  );
}

## Versioning (do this with every change)

In the same edit as every code change, overwrite `.ai-versions/pending.json` with:

```json
{
  "bump": "patch",
  "summary": "One line: what changed (max 100 chars)",
  "reason": "One line: why this bump level",
  "prompt": "The user's request, shortened to one line"
}
```

Choose `bump`:
- `patch`: small tweak, same features. Colors, text, spacing, sizes, icons, a small bug fix.
- `minor`: something new, same design direction. New section, component, page, form, feature or integration.
- `major`: direction changed. Full redesign, new layout or navigation, new design system, removing a feature or page, changing the data model.
- Unsure between two levels: pick the lower one and say so in `reason`.

## Going back to a version

When the user asks to go back to a version ("go back to v3.4.5", "undo the redesign"):
- Don't change any code, and don't touch `pending.json`. Write only `.ai-versions/restore.json`:
  `{ "version": "v3.4.5", "note": "why, in one line" }`
- If they describe a version instead of giving a number, find it in `public/ai-versions.json` (each version has a summary and the prompt). If more than one could match, ask which.
- Tell the user: GitHub brings that exact version back in about 1 to 2 minutes, and the preview updates when it syncs. It's saved as a new version, so nothing is lost and they can go back again.
- Once the code has gone back, treat it as the truth. Don't re-apply changes from versions after the restored one unless the user asks for them again.

## Rules

- Never edit or delete `.github/`, `public/ai-versions.json`, `src/components/VersionPill.tsx`, or anything else in `.ai-versions/`, except `pending.json` and `restore.json` as described above.
- Keep `<VersionPill />` rendered once in the root layout (`src/routes/__root.tsx`, or `src/App.tsx` in older apps). It only shows in the preview, never on the live site.
- Never invent version numbers. GitHub assigns them about a minute after each change.
- If the user says a level was wrong ("that was major"), use their judgment for similar changes from now on and mention it in `reason`.
- Commits named "Update version list" or "Restore vX (asked in chat)" are automatic. Never treat them as user changes.
